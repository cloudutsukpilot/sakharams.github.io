**Make** is the oldest build tool still in daily use: a `Makefile` lists targets, their
prerequisites and the shell commands that produce them. **GNU Autotools** (Autoconf + Automake)
sits on top of Make to generate portable `configure` scripts and Makefiles. Much of the Linux and
open-source world (and many embedded and legacy enterprise codebases) still builds this way, so
DevOps engineers meet it regularly.

## At a glance

| Category | Common tools |
|---|---|
| Build tools | GNU Make, BSD make, Autoconf, Automake, Libtool, pkg-config; Bear (generates `compile_commands.json`) |
| Compilers | GCC, Clang |
| Dependencies | System packages (`apt`, `dnf`), pkg-config, vendored sources |
| Build files | `Makefile`, `*.mk`, `configure.ac`, `Makefile.am`, `autogen.sh`, `m4/` macros; generated: `configure`, `Makefile.in`, `config.h` |
| Lint and format | clang-tidy (via Bear), cppcheck, clang-format, `-Wall -Wextra -Werror` |
| SAST (open source) | Clang Static Analyzer (`scan-build`), cppcheck, Flawfinder, CodeQL, Semgrep |
| SAST (commercial) | Coverity, Klocwork, CodeSonar, Polyspace, Fortify, Checkmarx One |
| Runtime checks | AddressSanitizer, UBSan, Valgrind, fuzzing with AFL++ |
| SCA | Black Duck (snippet matching), Mend, Syft/Grype on the resulting OS packages or image |
| Libraries | GLib, OpenSSL, libcurl, zlib (found with pkg-config) |
| Test and coverage | `make check` (Automake test harness), Check, CUnit, GoogleTest; gcov + gcovr / lcov |
| Build output | Executables, `.a` / `.so` libraries, source tarballs (`make dist`), `.deb` / `.rpm` |
| CI cache | ccache directory |

## How the build works

In CI, each stage of the [generic build pipeline](/posts/devops/build-tools/language-build-ecosystem/#generic-pipeline) maps to a Make / Autotools command, plugin or scanner. Press play, or step through it:

{% include flow-anim.html id="devops/build-tools/cpp/make-autotools-ci-pipeline" %}

- **Make** rebuilds a target when any prerequisite is newer than the target (timestamp-based).
  Recipes are shell commands and **must be indented with a tab**.
- **Autotools** is a generator: maintainers run `autoreconf` to produce `configure`; users and CI
  run `./configure && make`. Release tarballs ship the generated `configure` so users do not need
  Autotools installed.
- **`make distcheck`** builds the tarball, unpacks it, builds and tests it out of tree, and
  installs it to a temporary prefix; it is the best release gate for Autotools projects.

## Build files

| File | Purpose | Commit? |
|---|---|---|
| `Makefile` | Targets, prerequisites and recipes (plain Make projects) | Yes |
| `*.mk` | Included Makefile fragments | Yes |
| `configure.ac` | Autoconf input: checks for compilers, headers, libraries | Yes |
| `Makefile.am` | Automake input: programs, sources, tests | Yes |
| `autogen.sh` | Convenience wrapper for `autoreconf -fi` | Yes |
| `m4/` | Custom Autoconf macros | Yes |
| `configure`, `Makefile.in`, `aclocal.m4`, `config.h.in` | Generated by Autotools | No in git, yes in release tarballs |
| `config.log`, `config.status`, `Makefile` (generated) | Results of `./configure` | No |

## Commands by category

```bash
autoreconf -fi && ./configure CFLAGS="-O2 -Wall -Wextra -Werror"   # generate + configure
make -j"$(nproc)"                                # build
bear -- make -j"$(nproc)"                        # build and record compile_commands.json
clang-tidy -p . src/*.c                          # lint (needs compile_commands.json)
scan-build --status-bugs make -j"$(nproc)"       # SAST (Clang Static Analyzer)
cppcheck --enable=warning,portability --error-exitcode=1 src/   # SAST
make check                                       # tests
make CFLAGS="--coverage -O0" check && gcovr -r . --fail-under-line 80   # coverage gate
make distcheck                                   # release tarball + full verification
```

## Minimal project

A plain `Makefile` with automatic header dependency tracking (recipes use tabs):

```makefile
CC      ?= cc
CFLAGS  ?= -O2 -Wall -Wextra -Werror
CFLAGS  += -MMD -MP
SRC     := $(wildcard src/*.c)
OBJ     := $(SRC:src/%.c=build/%.o)

.PHONY: all clean check
all: build/demo

build/demo: $(OBJ)
	$(CC) $(LDFLAGS) -o $@ $^ $(LDLIBS)

build/%.o: src/%.c | build
	$(CC) $(CFLAGS) -c -o $@ $<

build:
	mkdir -p build

check: build/demo
	./tests/run.sh

clean:
	rm -rf build

-include $(OBJ:.o=.d)
```

<details markdown="1">
<summary>Same project with Autotools (<code>configure.ac</code> + <code>Makefile.am</code>)</summary>

```text
# configure.ac
AC_INIT([demo], [1.0.0])
AM_INIT_AUTOMAKE([foreign -Wall -Werror subdir-objects])
AC_PROG_CC
PKG_CHECK_MODULES([CURL], [libcurl])
AC_CONFIG_FILES([Makefile])
AC_OUTPUT
```

```makefile
# Makefile.am
bin_PROGRAMS = demo
demo_SOURCES = src/main.c
demo_CFLAGS  = $(CURL_CFLAGS)
demo_LDADD   = $(CURL_LIBS)

TESTS = tests/run.sh
```

</details>

## Frameworks and libraries

| Library | Use it from Make / Autotools |
|---|---|
| libcurl | `PKG_CHECK_MODULES([CURL], [libcurl])` or `$(shell pkg-config --cflags --libs libcurl)` |
| OpenSSL | `PKG_CHECK_MODULES([SSL], [openssl])` |
| GLib | `PKG_CHECK_MODULES([GLIB], [glib-2.0])` |
| Check (unit tests) | `PKG_CHECK_MODULES([CHECK], [check])` + `TESTS = tests/check_demo` |

## CI with GitHub Actions

{% raw %}
```yaml
name: make-ci
on: [push, pull_request]
permissions:
  contents: read

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: sudo apt-get update && sudo apt-get install -y autoconf automake libtool pkg-config libcurl4-openssl-dev cppcheck clang-tools bear gcovr
      - uses: hendrikmuhs/ccache-action@v1.2
        with:
          key: ${{ runner.os }}-make

      - run: autoreconf -fi
      - run: ./configure CC="ccache gcc" CFLAGS="-O2 -Wall -Wextra -Werror"
      - run: scan-build --status-bugs make -j"$(nproc)"
      - run: cppcheck --enable=warning,portability --error-exitcode=1 src/
      - run: make check
      - run: make distcheck

      - uses: actions/upload-artifact@v4
        with:
          name: tarball
          path: '*.tar.gz'
```
{% endraw %}

## Best practices

- **Declare `.PHONY` targets** and use `-MMD -MP` so header changes trigger rebuilds.
- **Build in parallel** with `make -j"$(nproc)"`, and make sure the dependency graph is complete so
  parallel builds are deterministic.
- **Do not commit generated Autotools files**; generate them in CI with `autoreconf -fi` and ship
  them only in release tarballs.
- **Gate releases on `make distcheck`**.
- **Use `DESTDIR`** for staged installs when packaging (`make install DESTDIR=$PWD/pkgroot`).
- **Generate `compile_commands.json` with Bear** so modern linters and analyzers work on Make
  projects.
- **Consider migrating** large or cross-platform projects to CMake or Meson; keep Make as a thin
  task runner if the team likes `make test` / `make lint`.
