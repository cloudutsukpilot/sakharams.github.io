# 2026-10-01

Theme sync with jekyll-theme-chirpy 7.6.0, customization tests, and fluid content width.

## Theme sync (Chirpy 7.6.0)

Gem versions were already current (Chirpy 7.6.0, Jekyll 4.4.1), but two local overrides were copies of
older Chirpy files.

- **`_layouts/default.html`**: rebuilt from the 7.6.0 layout, then the AdSense blocks and panel order
  were added back. The old copy came from Chirpy 6.x, which caused three problems:
  - Giscus comments never loaded. The layout skipped `layout.script_includes`, so the comment script
    was missing from all 691 posts.
  - `theme_mode` would not have worked. The layout set `data-mode` instead of `data-bs-theme`.
  - Chirpy's JavaScript loaded twice (`js-selector.html` in both `<head>` and `<body>`). This is the
    likely cause of Mermaid diagrams rendering twice.
- **`assets/css/jekyll-theme-chirpy.scss`**: rebuilt on the 7.6.0 entry file. The missing
  `@use 'abstracts/variables' with ($theme: ...)` line meant `theme_mode` could not reach the CSS.
- **`_includes/analytics/google.html`**: removed. It was the same as the theme's copy.

## New 7.x features enabled

- "Edit this post" link on every post (`actions.edit_post`), pointing to
  `github.com/cloudutsukpilot/sakharams.github.io/edit/main/<post path>`.
- `social.fediverse_handle` setting added (empty; fill it in to emit the `fediverse:creator` meta tag).

## Fluid content width

Chirpy has no config option for this. From 1650px up it caps the content at
`$main-content-max-width: 1250px`. That limit is now 1920px, so posts and the post list fill the
window up to 2220px-wide screens. The back-to-top button and search box position, which assumed the
content was always exactly the limit, are recalculated from the actual width.

## Post breadcrumb

Posts showed `Home › <title>`: Chirpy's top bar skips the middle URL segments on posts. New override
`_includes/topbar.html` (7.6.0 copy plus one block) adds the post's categories, each linked to its
category page: `Home › devops › build-tools › swift › <title>`. Long paths shorten the title with "…"
on narrower screens as before. Tested in `test/breadcrumb_test.rb`, which also checks that every
breadcrumb link on all posts points to an existing category page.

## Expedition Map

The Site Map post (`_posts/2025-03-20-map.md`) was 1,352 lines of hand-written HTML linking 171 of
~690 posts, with 37 placeholder `href="#"` links and empty sections. It is now generated from post
categories as an interactive map: 9 countries (Cloud, DevOps, Security, AI & ML, Architecture,
Infrastructure, Programming, Homelab & Projects, Career & Field Notes) and 75 states covering all 690
posts. Same URL, still pinned.

- New: `_data/expedition_map.yml`, `_plugins/expedition_map.rb`, `_includes/expedition-map.html`,
  `assets/js/expedition-map.js`, `_sass/expedition-map.scss`, `_tabs/map.md` ("Expedition Map" tab,
  first after Home).
- Map: Voronoi-treemap regions sized by post count; hover tooltips; click a country to zoom, a state
  to list its posts in the travel guide; search; deep links (`#devops/cicd`); keyboard access.
  Below 850px only the Atlas is shown.
- Fullscreen view (button on the map; Esc zooms out, then exits) and a real world map background
  (Natural Earth projection) under semi-transparent topic regions. State labels are sized in screen
  pixels so they stay readable inline and in fullscreen.
- Fixed `_posts/cloud/azure/2024-08-18-microsoft-interactive-guides.md`: a blank line before `---`
  meant its front matter was shown as text on the live page. The URL is kept with `permalink:`.
- Tests: `test/expedition_map_test.rb` (placement rules, every post on the map, links, stats,
  script order, tab and canonical URL).

## Tests

New Minitest suite in `test/` that checks the built site. Run it with `task test-custom`, and in CI
via a new "Test customizations" step in `.github/workflows/pages-deploy.yml`.

| File | Covers |
|---|---|
| `test/adsense_test.rb` | Ad slots and placement, panel order, publisher ID, `ads.txt` |
| `test/mermaid_test.rb` | Fullscreen wrapper and button, script parses after compression, custom CSS |
| `test/config_test.rb` | Analytics, permalinks, tabs, `_data` contact/share, excludes, social links, `${{ }}` escaping |
| `test/theme_sync_test.rb` | Overrides keep every upstream Chirpy line, Giscus, edit link, scripts load once |
| `test/layout_width_test.rb` | Raised width limit, back-to-top and search box recalculation |
| `test/breadcrumb_test.rb` | Post category path, links resolve, other pages unchanged |
| `test/expedition_map_test.rb` | Map placement rules, every post on the map, links, stats, tab |

`minitest` was added to the `:test` group in the `Gemfile`.

Results: before the changes, all tests for existing customizations passed and the theme-sync tests
failed as expected. After the changes, all 55 tests pass.
